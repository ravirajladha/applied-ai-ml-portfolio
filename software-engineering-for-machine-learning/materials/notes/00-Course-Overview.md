# Course Overview — SE4ML (AIMLCZG546)

> Source: Session 1 course-handout slides. This is the "map of the whole course" — read once, then use it to place each session.

## 🎯 What the course is about

Turning a **trained ML model** into a **real, running product** other people depend on. Training the model is the easy 10%; the engineering *around* it is the 90% this course teaches.

## Course objectives (COs)

| # | Objective |
|---|-----------|
| CO1 | Understand the transition from ML **models** to production-ready software **systems**. |
| CO2 | Apply software-engineering principles to design & build ML-enabled systems. |
| CO3 | Analyse & define **requirements, architecture, and quality attributes** for ML apps. |
| CO4 | Develop & test robust, scalable ML **pipelines** using good coding + MLOps practices. |
| CO5 | Evaluate **ethical, security, and operational** aspects of real-world ML systems. |

## Module map (the 8 modules)

```
1. Foundations of ML Systems Engineering      ← Sessions 1–2
2. Requirements Engineering for ML Systems     ← Session 3
3. Architecture & Design                       ← Sessions 4–6
4. Implementation and Code Sharing             ← Session 9 (current)
5. Quality Assurance
6. Deployment
7. Responsible ML Engineering
8. Application of SE Principles for Agentic AI  ← Session 7
```

## 🧰 Tools & platforms used

| Purpose | Tool |
|---------|------|
| Pipeline orchestration | **Prefect** / Prefect Cloud |
| Experiment tracking & model management | **MLflow** |
| Data versioning | **DVC** |
| Cloud ML platform | **Amazon SageMaker** |
| Containers & orchestration | **Docker**, **Kubernetes** (Minikube) |
| API development | **FastAPI** |
| Testing & monitoring | **PyTest**, **Evidently AI** |
| RAG pipeline | **LangChain**, **ChromaDB**, OpenAI embeddings + LLM |

> 💡 Notice how much of this is *software engineering* tooling, not model math. That is the whole point.
