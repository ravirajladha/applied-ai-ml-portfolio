Question 4. [1.5 + 1.5 + 3 = 6 Marks]

Consider the sentence: "Birds build nests"

You are given:

  • Attention weights for 'build': α = [0.3, 0.5, 0.2] (for Birds, build, nests)
  • Value vectors: v_Birds = [2,1], v_build = [1,3], v_nests = [0,2]

(a) Explain what contextual embeddings are and why they are important in NLP. [1.5 marks]

(b) How do contextual embeddings differ from static word embeddings like Word2Vec? [1.5 marks]

(c) Using the given attention weights and value vectors, calculate the contextual embedding (output) for the word 'build'. Then, given a second attention head produced head₂ = [0.5, 0.8], compute the final multi-head output using W_O = [[0.2,0.5],[0.4,0.1],[0.6,0.3],[0.1,0.2]]. Show all steps. [3 marks]

Show answer — Q4 Set A

(a) Contextual embeddings are vector representations of words that change based on the surrounding context. Unlike static embeddings, the same word can have different representations in different sentences. Importance: capture word sense disambiguation (bank financial vs river); enable better understanding of semantic relationships; improve performance on downstream NLP tasks.

(b)

Static (Word2Vec, GloVe) Contextual (BERT, ELMo)
One fixed vector per word, regardless of context Dynamic vectors that change with context
Cannot handle polysemy Same word gets different representations per sentence
One vector per word type One vector per word token
Trained by prediction over a window Computed using attention over the whole sequence

(c) [3 marks]

Step 1 — contextual embedding = weighted sum of value vectors

  Output = 0.3 x [2,1]  +  0.5 x [1,3]  +  0.2 x [0,2]
         = [0.6, 0.3]   +  [0.5, 1.5]   +  [0, 0.4]
         = [ 0.6+0.5+0 , 0.3+1.5+0.4 ]
         = [ 1.1 , 2.2 ]                    <- head_1

  (check: weights sum to 0.3+0.5+0.2 = 1.0 ✓)

Step 2 — concatenate the two heads

  Concat(head_1, head_2) = [1.1, 2.2, 0.5, 0.8]      (4-vector, matches W_O's 4 rows ✓)

Step 3 — project through W_O

  c1 = 1.1x0.2 + 2.2x0.4 + 0.5x0.6 + 0.8x0.1
     = 0.22 + 0.88 + 0.30 + 0.08 = 1.48

  c2 = 1.1x0.5 + 2.2x0.1 + 0.5x0.3 + 0.8x0.2
     = 0.55 + 0.22 + 0.15 + 0.16 = 1.08

  FINAL MULTI-HEAD OUTPUT = [1.48 , 1.08]

Question 7. [3 + 1 + 2 = 6 Marks]

Consider a document summarization task with the topic (query):

q: "Impact of electric vehicles on urban air quality."

One sentence has already been selected in the summary:

S = {"Electric vehicles reduce tailpipe emissions in city centres."}

Two candidate sentences are being evaluated next:

  • S1: "EV adoption has cut nitrogen dioxide levels across major metropolitan areas."
  • S2: "Electric cars produce no exhaust emissions in urban areas."
Sentence sim(s, q) sim(s, S)
S1 0.85 0.60
S2 0.78 0.25

Given λ = 0.7:

  1. Compute the MMR score for both sentences. [3 marks]
  2. Identify which sentence will be selected next. [1 mark]
  3. Justify your answer logically (relevance vs redundancy). [2 marks]
Show answer — Q7 Set A 
MMR(s) = lambda * sim(s,q)  -  (1 - lambda) * sim(s,S)

lambda = 0.7 ,  (1 - lambda) = 0.3

1. MMR(S1) = 0.7 x 0.85  -  0.3 x 0.60
           = 0.595       -  0.18
           = 0.415                                  (1.5 marks)

   MMR(S2) = 0.7 x 0.78  -  0.3 x 0.25
           = 0.546       -  0.075
           = 0.471                                  (1.5 marks)

2. MMR(S2) > MMR(S1)  =>  SENTENCE S2 IS SELECTED.   (1 mark)

3. Justification [2 marks]

Although S1 is more relevant to the topic (0.85 vs 0.78), it is far more similar to the already-selected sentence (0.60 vs 0.25), making it redundant — it would largely repeat information the summary already contains. S2 contributes lower redundancy and therefore achieves a higher MMR score. MMR deliberately trades a little relevance for novelty, so the summary covers more distinct information overall.

Question 5. [2 + 2 + 2 = 6 Marks]

(a) Define homonymy and polysemy, giving one example of each, and state why homonymy causes problems for NLP applications. Name two such applications. [2 marks]

(b) Why does WordNet perform poorly in domain-specific texts (e.g. medical or legal)? Suggest one solution. [2 marks]

(c) Explain the difference between the lexical sample task and the all-words task in Word Sense Disambiguation. [2 marks]

Show answer — Q5 Set B

(a) [2 marks]

Homonymy — lexemes that share a form (phonological, orthographic or both) but have unrelated, distinct meanings. Example: bat (wooden stick) vs bat (flying mammal); bank (financial institution) vs bank (riverside).

Polysemy — a single lexeme with multiple related meanings. Example: bank the building vs bank the financial institution.

Why homonymy is a problem: the same form must be resolved to different meanings or pronunciations.

  • Text-to-speech — same orthographic form, different phonological form (bass the fish vs bass the voice).
  • Information retrieval — the query "bat care" is ambiguous.
  • Also machine translation and speech recognition.

(b) [2 marks]

WordNet performs poorly in domain-specific texts because it is a general-purpose lexical database and lacks specialised technical vocabulary. Many medical or legal terms are missing or insufficiently defined. Solution: combine WordNet with a domain-specific ontology or lexicon, which improves accuracy by adding expert domain knowledge.

(c) [2 marks]

Lexical sample task — a small pre-selected set of target words, with an inventory of senses for each. Because the word set and sense set are small, simple supervised classification approaches work very well.

All-words task — the system is given entire texts plus a lexicon with a sense inventory for each entry, and must disambiguate every word in the text (or sometimes just every content word).

ROUGE = Recall-Oriented Understudy for Gisting Evaluation. An intrinsic metric for automatically evaluating summaries, based on BLEU (a machine-translation metric). Not as good as human evaluation, but much more convenient.

ROUGE-2: given a document D and an automatic summary X, have N humans produce reference summaries. It measures what percentage of the bigrams from the reference summaries appear in X.

   ROUGE-2  =  ---------------  =  ----  =  0.3846  =  38.5%
                     6 + 7          13

(c) [2 marks]

1. CONTENT SELECTION    — choose sentences to extract from the document
2. INFORMATION ORDERING — choose an order to place them in the summary
3. SENTENCE REALIZATION — clean up the sentences

  • Attend to information from different representation subspaces

  • Increase model capacity without proportionally increasing computation

   => Head 1 focuses on the VERB / action word (syntactic relationship)

Answer: mouse_N1, the small rodent (cosine = 1.0).

Trap avoided: N1 also has the largest dot product here, but that is not the reason — always divide by the magnitudes. [6,2,8] = 2 × [3,1,4], the same direction, hence cosine exactly 1.

(b) [3 marks]

Hyponymy — one sense is a hyponym of another if the first is more specific, denoting a subclass of the other. car is a hyponym of vehicle; dog is a hyponym of animal; mango is a hyponym of fruit.

Hypernymy — the converse relation, the superordinate. vehicle is a hypernym of car; animal is a hypernym of dog.

Synset — the set of near-synonyms for a WordNet sense is called a synset (synonym set). It is WordNet's version of a sense or concept; all members share the same gloss, and for WordNet the meaning of that sense is this list.

(c) [2 marks]

In a research publication ontology, RDF is used to represent factual data, while OWL is used to define semantics and constraints.

Using RDF, entities such as Paper, Author and Conference are represented as resources and linked using triples: (Paper1, hasAuthor, Author1), (Paper1, presentedAt, Conference1).

Using OWL, classes and relationships are formally defined. Classes include Paper, Author, Conference; object properties include hasAuthor and presentedAt. OWL can also specify constraints such as every Paper must have at least one Author, enabling reasoning and consistency checking.

Question 7. [3 + 1.5 + 1.5 = 6 Marks]

A media monitoring company is building an NLP summarization system. It must support:

  1. An editor uploads a single long investigative report and wants a headline and a short abstract.
  2. An analyst supplies 20 articles from different agencies covering the same election result and wants one concise overview.
  3. A lawyer uploads a contract and asks: "Summarize only the clauses relevant to termination penalties."

(a) Identify the type of summarization required for each scenario. [3 marks] (b) Justify your choices by explaining the key characteristics of each type. [1.5 marks] (c) Two candidate sentences are scored against a query with λ = 0.8: S1: sim(q)=0.90, sim(S)=0.40 and S2: sim(q)=0.70, sim(S)=0.15. Compute both MMR scores and state which is selected. [1.5 marks]

Show answer — Q7 Set C

(a) [3 marks]

Scenario Required summarization type
1 Single-document, Generic summarization
2 Multi-document summarization
3 Query-focused summarization

(b) [1.5 marks]

1. SINGLE-DOCUMENT, GENERIC
   - Operates on ONE document
   - Produces outputs such as a headline, abstract, or outline
   - Focuses on the OVERALL CONTENT, not a specific query

2. MULTI-DOCUMENT
   - Takes a group of documents related to the SAME EVENT
   - Produces a gist of shared information, REMOVING REDUNDANCY and
     resolving overlaps across sources
   - Commonly used for news aggregation and event summarization

3. QUERY-FOCUSED
   - Tailors the summary to a SPECIFIC USER INFORMATION NEED
   - Acts as a form of COMPLEX QUESTION ANSWERING
   - Ignores unrelated sections of the document

(c) [1.5 marks]

MMR(s) = lambda x sim(s,q) - (1 - lambda) x sim(s,S)
lambda = 0.8 ,  (1 - lambda) = 0.2

MMR(S1) = 0.8 x 0.90 - 0.2 x 0.40 = 0.72 - 0.08 = 0.64
MMR(S2) = 0.8 x 0.70 - 0.2 x 0.15 = 0.56 - 0.03 = 0.53

MMR(S1) > MMR(S2)  =>  SENTENCE S1 IS SELECTED.

Note the contrast with Set A. Here the more relevant sentence wins, because λ = 0.8 weights relevance heavily and S1's redundancy (0.40) is not high enough to overcome its 0.20 relevance advantage. λ controls the trade-off — do not assume the less-relevant sentence always wins.
